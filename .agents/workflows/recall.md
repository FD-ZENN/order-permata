# Alur Kerja Recall (/recall)

Gunakan alur kerja ini untuk mengingat kembali konteks, keputusan masa lalu, atau skema proyek tanpa mengulang analisis dari awal.

## Langkah Eksekusi:
1. **Identifikasi Topik**:
   - Tanyakan kata kunci atau topik spesifik jika belum disebutkan oleh pengguna (misal: nama tabel, fitur compiler, tema tertentu).
2. **Pencarian Memori**:
   - Cari kata kunci terkait di:
     - `docs/MEMORY.md` (menggunakan kategori atau tag seperti `#database`, `#compiler`, dsb.)
     - `docs/SCHEMA.md` (untuk relasi & struktur tabel)
     - `docs/PROGRESS.md` (untuk status pengerjaan fitur)
3. **Sajikan Hasil Pencarian**:
   - Tampilkan entri yang cocok lengkap dengan tanggal pencatatan, ringkasan keputusan, dan lokasi file terkait.
4. **Kejujuran Informasi**:
   - Jika informasi yang dicari tidak ditemukan di memori persisten, katakan secara terus terang dan jangan menebak/mengarang.
